# Identidad

Nombre visible: **SintaxTrama**. Autoría y copyright: **G9C_Studios**. Licencia del producto: MIT.

El símbolo sin palabras combina un libro abierto, un umbral central y una esquina plegada. Usa lavanda sobre carbón y mantiene la identidad visual aprobada. El original se generó con la herramienta de imágenes; los tamaños Windows se derivaron con Tauri.

`public/pliegra-symbol.png` y `src-tauri/icons/` conservan sus nombres de recurso para evitar cambios innecesarios. El ejecutable interno, las claves de instalación Pliegra y el identificador local.esteban.linde también se mantienen por compatibilidad; no son el nombre visible del producto.
